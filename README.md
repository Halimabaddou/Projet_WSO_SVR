# Prédiction des besoins de chauffage : SVR + WSO

**Réalisé par : BADDOU Halima et EL GOUDE Meriem**  
Master Intelligence Artificielle (IAA)  
Université Ibn Zohr — Faculté des Sciences Appliquées de Ouarzazate

Ce projet utilise un modèle de régression SVR à noyau RBF pour prédire le besoin de chauffage des bâtiments. Une adaptation pédagogique de White Shark Optimizer (WSO) recherche les hyperparamètres `C`, `gamma` et `epsilon`. Les performances sont comparées à celles d'un SVR initial et d'une recherche aléatoire.
